# 数阔夜校 · AI 不是帮你干活，是帮你长能力

[打开在线展示](https://yyfyydshh.github.io/shukuo-ai-night-school/)

一套适合现场讲解的中文互动展示，共 11 页，包含视频 Skill、Remotion 知识动画、Git 概念演练与「找、借、改、存」。

## 使用

方向键翻页；F 全屏；G 目录；N 讲解提示。触屏可点选操作。

下载整个仓库后，也可以直接打开 `index.html` 离线展示。两段视频随项目提供。

## 发布

GitHub Pages 从 `main` 分支根目录发布，推送更新后自动部署。纯静态 HTML/CSS/JavaScript，无须安装依赖或构建。

详细操作见 `使用说明.md`，讲解参考见 `讲者手册.html`。
